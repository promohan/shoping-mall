# 🏬 Mohan Mega Mall

Welcome to **Moh Mega Mall** — a modern and responsive shopping mall website built using HTML, CSS, and JavaScript.  
This project showcases a stylish, user-friendly interface that simulates an online mall experience, complete with featured brands, exclusive deals, and product listings.

---

## 🌐 Live Demo
🔗 [View Website](https://promohan.github.io/shoping-mall/)

---

## 📸 Features

- 🛍️ **Home Page:** Engaging hero section with promotional banners and discounts  
- 🏷️ **Featured Brands:** Showcase of top fashion, tech, and lifestyle brands  
- 💎 **Featured Products:** Product cards with names, prices, and images  
- 📞 **Contact Section:** Includes phone, email, and address details  
- 🌙 **Responsive Design:** Fully optimized for mobile, tablet, and desktop devices  
- 💅 **Modern UI:** Built using semantic HTML, organized CSS, and clean JavaScript
